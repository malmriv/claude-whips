# claude-whips
I will use this repo to maintain some skills that I use frequently.

Claude and other LLMs are very good at producing boilerplate code, or code that kind of lives in no-mans-land. Code that will run within an empty Java project, or an unconfigured IDE, or for a POC that uses Python. Unfortunately, the word is complicated and some of my activities are very niche or context-dependent. Claude (currently) sucks at producing code that will survive any security review, or even run, in some of these real-case scenarios. These skills attempt to lighten the load on the operator (i.e. me) so that Claude can have the full picture from the start.

The idea to share these comes from an interesting article I read recently: [I speak to Claude more than everyone in my life combined](https://ossama.is/writing/fatigue).
